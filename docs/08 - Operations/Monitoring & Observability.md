# 🔭 Monitoring & Observability

- **Structured Logging**: JSON logging via Winston with timestamp, service name, duration, and correlation ID.
- **Log Aggregation**: Logs streamed to ELK / Grafana Loki.
- **Metrics**: Prometheus metrics scraping endpoints for request rates and Kafka consumer lag.
